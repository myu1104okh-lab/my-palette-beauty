# My Palette Beauty

写真を撮るだけでパーソナルカラーを診断し、似合うコスメが見つかるアプリです。
**APIキー不要・完全無料**で公開できます。

## 機能

- **パーソナルカラー診断** — 肌・瞳・髪・手のひら・血管の写真から、イエベ春 / ブルベ夏 / イエベ秋 / ブルベ冬を判定
- **コスメランキング** — カテゴリ別・ブランド別・パーソナルカラー別に絞り込み
- **口コミ** — 星評価とコメントの投稿
- **マイページ** — 診断結果、似合うコスメ、お気に入り一覧

診断は CIELAB 色空間(国際規格の色空間)で肌の色を実測し、黄み・赤み・明るさから判定します。すべてブラウザ内で完結するので、写真がどこかに送信されることはありません。

## GitHub Pages で公開する手順

### 1. リポジトリを作る

GitHub で新しいリポジトリを作ります。名前は **`my-palette-beauty`** にしてください。

> 別の名前にする場合は、`vite.config.js` の `base` をその名前に書き換えてください。
> 例:リポジトリ名が `pc-app` なら `base: "/pc-app/"`

### 2. ファイルをアップする

このフォルダの中身をリポジトリに push します。

```bash
git init
git add .
git commit -m "初回コミット"
git branch -M main
git remote add origin https://github.com/ユーザー名/my-palette-beauty.git
git push -u origin main
```

> GitHub のサイト上でドラッグ&ドロップでアップロードしてもかまいません。
> その場合、`.github` フォルダも忘れずに含めてください。

### 3. GitHub Pages を有効にする

1. リポジトリの **Settings** を開く
2. 左メニューの **Pages** をクリック
3. **Source** を **GitHub Actions** に変更

これだけです。数分後、次のURLで公開されます。

```
https://ユーザー名.github.io/my-palette-beauty/
```

以降は push するたびに自動で更新されます。

## 注意

- **商品データも評価も実在のものです。** `src/App.jsx` の `PRODUCTS` は各ブランド公式サイト等で確認した商品名・実勢価格・公式商品画像です。ランキングの順位は `cosme` フィールドの評価(@cosme 掲載の7点満点、2026年8月3日取得)にもとづきます。価格・件数は変動するため、最新情報は各リンク先で確認してください。
- **@cosme の評価はシリーズ単位です。** 色ごとの評価ではありません(@cosme のカラー別ページもシリーズの値を返すため、色別データは存在しません)。
- **@cosme の評価とアプリ内の口コミは混ぜていません。** 数万件規模の実評価に数件の投稿を平均すると実態と食い違うため、別々に集計・表示しています。
- **診断結果は参考です。** 写真の照明や画質で結果が変わります。正確な診断はプロのドレープ診断をおすすめします。
- **カメラは HTTPS でのみ動きます。** GitHub Pages は自動で HTTPS になるので問題ありません。
- **口コミとお気に入りは端末内に保存されます。** 他の人とは共有されません。共有したい場合は Supabase などのデータベース導入が必要です。

## 商品データの差し替え方

`src/App.jsx` の `PRODUCTS` を編集します。

```js
{
  id: "p01",                    // 重複しない ID
  name: "商品名",
  brand: "ブランド名",
  cat: "リップ",                 // リップ / チーク / アイシャドウ / ノーズシャドウ / アイライナー / マスカラ / ベースメイク
  price: 1500,
  seasons: ["spring"],          // 似合うタイプ spring / summer / autumn / winter
  cosme: {                      // @cosme の実際の評価。省略すると「評価データなし」と表示され、順位は末尾になります
    rating: 5.4,                //   7点満点の平均(@cosme の表記のまま。5点満点に換算しないこと)
    count: 29066,               //   クチコミ件数
    id: "10206485",             //   https://www.cosme.net/products/<id>/ の商品ID
  },
  color: "#FF8E75",             // イラストに使う色
  img: "写真のURL",              // 任意。指定すると写真が表示されます
}
```

`cosme` の値は必ず @cosme の商品ページで実際に確認した数値を入れてください。推測で埋めると、順位に根拠がなくなります。
値を更新したら `COSME_FETCHED_AT`(取得日の表示)も併せて直してください。

ブランドを追加した場合は `BRANDS` にも名前を足してください。

## あとから AI 診断を追加したい場合

Anthropic API を使うと、写真からより詳しい分析コメントを生成できます。
その場合は API キーと、キーを安全に扱うサーバー(Vercel など)が必要になります。
